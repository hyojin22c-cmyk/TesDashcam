Before you start

Are my videos uploaded?+

Video processing runs on your device. Opening the web app and loading map tiles may use the network.

Which clips can I open?+

Use unencrypted TeslaCam MP4 files from RecentClips, SavedClips or SentryClips. Some recordings do not contain telemetry.

Can I use external storage on iPhone?+

Yes. Opening a folder is the normal workflow. On USB 2.0 iPhones connected over OTG, reading many files can be slow. In that case, select only the files you need or copy them to the phone first.
