Avant de commencer

Mes vidéos sont-elles envoyées ?+

Le traitement vidéo se fait sur votre appareil. L’ouverture de l’application web et le chargement des cartes peuvent utiliser le réseau.

Quels clips puis-je ouvrir ?+

Utilisez les MP4 TeslaCam non chiffrés de RecentClips, SavedClips ou SentryClips. Certains enregistrements n’ont pas de télémétrie.

Puis-je utiliser un stockage externe sur iPhone ?+

Oui. Ouvrir un dossier est le fonctionnement normal. Sur un iPhone USB 2.0 connecté en OTG, la lecture de nombreux fichiers peut être lente. Sélectionnez alors les fichiers utiles ou copiez-les d’abord sur le téléphone.
